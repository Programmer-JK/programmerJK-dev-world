## 한 일

- **배포**: 이미지를 tar로 옮기고, 서버에서 로드해 컨테이너로 띄우고, nginx 리버스 프록시를 붙였다. 재부팅 때 자동으로 컨테이너가 뜨게 하는 것까지 직접 해 봤다.
- **기능**: 이메일 인증, 할인 정책, 주문·결제·파일 API, 사업자등록증 OCR 연동, 관리자용 라이선스 조회 API(다중 조건 검색)를 만들었다.
- **AI 코딩 도구**: API 명세를 여섯 개의 프롬프트로 나눠 단계별로 생성했다. 큰 요청 하나보다 쪼갠 요청이 결과가 훨씬 안정적이었다.
- **마무리**: 9월에 프로젝트 종료 보고서를 쓰며 한 일을 정리했다.
- **방향 전환**: 그다음은 AI였다. sLLM, SLM, vLLM을 조사하고 LoRA 파인튜닝을 Colab에서 실험했다.

## 배운 것

- 프론트엔드만 하던 때는 "배포"가 버튼이었다. 직접 해 보니 로그, 재시작, 프록시 설정 하나하나가 서비스의 일부였다.
- AI 도구에게 일을 맡길 때도 결국 설계가 먼저다. 명세가 명확할수록 결과가 좋았다.
- [LLM, SLM, sLLM, vLLM은 서로 다른 층위의 말](/posts/sllm-slm-vllm)이다. 모델, 용도, 추론 엔진을 구분해야 선택이 쉬워진다.
