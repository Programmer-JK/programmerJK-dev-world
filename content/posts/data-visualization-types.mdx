## 1. 선 그래프(Line Chart)

### 특징

- 연속적인 데이터 포인트를 선으로 연결하여 표시
- X축은 주로 시간이나 순서가 있는 카테고리로 구성
- 추세와 패턴을 확인하는 데 탁월함

### 활용 예시

- 주식 가격 변동 추적
- 월간 매출 추이 분석
- 온도 변화와 같은 시간에 따른 측정값 변화
- 여러 제품의 판매 추이 비교(다중 선 그래프)

### 언제 사용해야 할까

- 시간에 따른 변화나 추세를 보여주고 싶을 때
- 데이터 포인트 간의 연속성을 강조하고 싶을 때
- 여러 데이터 세트의 추세를 비교하고 싶을 때

## 2. 파이 차트(Pie Chart)

### 특징

- 원을 여러 조각으로 나누어 전체에 대한 부분의 비율을 표시
- 각 조각의 크기는 해당 값이 전체에서 차지하는 비율을 나타냄
- 전체 중 각 부분이 차지하는 비중을 직관적으로 보여줌

### 활용 예시

- 시장 점유율 분석
- 예산 배분 현황
- 소비자 선호도 조사 결과
- 인구 통계학적 구성

### 언제 사용해야 할까

- 전체에 대한 부분의 비율을 보여주고 싶을 때
- 데이터 카테고리가 적을 때(일반적으로 5-7개 이하)
- 각 부분의 합이 100%인 데이터를 표현할 때
![](/notes-assets/20250228083934.png)
## 3. 영역 차트(Area Chart)

### 특징

- 선 그래프와 유사하지만, 선 아래 영역을 채워 강조
- 누적 영역 차트로 여러 카테고리의 합계와 구성을 동시에 표현 가능
- 전체 규모와 부분 구성 비율을 함께 보여줌

### 활용 예시

- 웹사이트 트래픽 소스별 분석
- 매출의 제품군별 기여도 변화
- 에너지 소비량의 연료 유형별 구성 변화
- 인구 구조의 시간에 따른 변화

### 언제 사용해야 할까

- 전체 볼륨과 그 구성 요소를 함께 보여주고 싶을 때
- 시간에 따른 누적 값의 변화를 표현하고 싶을 때
- 각 구성 요소의 상대적 기여도를 강조하고 싶을 때
![](/notes-assets/20250228083945.png)
## 4. 산점도(Scatter Plot)

### 특징

- 두 변수 간의 관계를 점으로 표시
- 각 점은 개별 데이터 포인트를 나타냄
- 상관관계, 클러스터, 이상치를 식별하는 데 유용

### 활용 예시

- 키와 몸무게의 상관관계
- 광고 지출과 매출의 관계
- 학습 시간과 시험 점수의 관계
- 제품 가격과 판매량의 관계

### 언제 사용해야 할까

- 두 변수 간의 관계나 패턴을 탐색하고 싶을 때
- 데이터 분포와 집중도를 보여주고 싶을 때
- 이상치(outlier)를 식별하고 싶을 때
![](/notes-assets/20250228083957.png)
## 5. 히트맵(Heat Map)

### 특징

- 데이터 값을 색상 강도로 표현
- 행과 열로 구성된 매트릭스 형태로 데이터를 시각화
- 복잡한 데이터 세트의 패턴을 색상으로 쉽게 식별 가능

### 활용 예시

- 웹사이트 클릭 행동 분석
- 요일/시간대별 트래픽 패턴
- 상관관계 매트릭스
- 지역별 판매 성과 비교

### 언제 사용해야 할까

- 다차원 데이터의 패턴을 한눈에 보여주고 싶을 때
- 행과 열로 구성된 데이터의 분포를 표현하고 싶을 때
- 값의 변화를 색상 강도로 직관적으로 전달하고 싶을 때
![](/notes-assets/20250228084228.png)
## 6. 방사형 차트(Radar Chart)

### 특징

- 여러 변수를 방사형으로 배치하여 다차원 데이터를 표현
- 각 축은 서로 다른 변수를 나타내며, 중심에서 멀어질수록 값이 커짐
- 여러 항목의 다차원 특성을 비교하는 데 유용

### 활용 예시

- 운동선수의 능력치 비교
- 제품의 다양한 속성 평가
- 직원 역량 평가
- 브랜드 인식 조사

### 언제 사용해야 할까

- 여러 카테고리에 걸친 성과를 비교하고 싶을 때
- 항목 간의 강점과 약점을 시각적으로 보여주고 싶을 때
- 3-10개 정도의 차원을 가진 데이터를 표현할 때
![](/notes-assets/20250228084012.png)
## 7. 박스 플롯(Box Plot)

### 특징

- 데이터의 분포, 중앙값, 사분위수, 이상치를 표시
- 여러 데이터 세트의 분포를 비교하는 데 유용
- 데이터의 통계적 특성을 compact하게 표현

### 활용 예시

- 학생들의 시험 점수 분포 비교
- 여러 지역의 소득 분포 비교
- 다양한 처리 방법의 효과 비교
- 센서 측정값의 변동성 분석

### 언제 사용해야 할까

- 데이터의 분포와 이상치를 함께 보여주고 싶을 때
- 여러 데이터 세트의 중앙 경향과 분산을 비교하고 싶을 때
- 데이터의 통계적 특성을 간결하게 요약하고 싶을 때
![](/notes-assets/20250228084026.png)
## 8. 트리맵(Treemap)

### 특징

- 계층적 데이터를 중첩된 사각형으로 표현
- 사각형의 크기는 값의 크기를 나타냄
- 색상은 다른 변수나 카테고리를 표현할 수 있음

### 활용 예시

- 회사 부서별/팀별 예산 배분
- 디스크 공간 사용량 분석
- 제품 카테고리별 매출 기여도
- 국가별/산업별 경제 규모

### 언제 사용해야 할까

- 계층적 데이터 구조를 보여주고 싶을 때
- 부분과 전체의 관계를 강조하고 싶을 때
- 공간을 효율적으로 사용하면서 많은 카테고리를 표현하고 싶을 때
![](/notes-assets/20250228084041.png)
## 9. 버블 차트(Bubble Chart)

### 특징

- 산점도의 확장 형태로, 세 번째 변수를 점의 크기로 표현
- X축, Y축, 버블 크기로 3개의 변수를 동시에 시각화
- 색상을 추가하여 네 번째 변수까지 표현 가능

### 활용 예시

- 국가별 GDP, 기대수명, 인구 비교
- 제품의 가격, 품질, 판매량 관계
- 웹사이트의 방문자 수, 체류 시간, 전환율 관계
- 산업별 성장률, 수익성, 시장 규모
![](/notes-assets/20250228084244.png)
### 언제 사용해야 할까

- 세 가지 이상의 변수 간 관계를 보여주고 싶을 때
- 데이터 포인트의 상대적 중요도나 크기를 강조하고 싶을 때
- 복잡한 데이터 세트의 패턴을 직관적으로 파악하고 싶을 때

## 10. 간트 차트(Gantt Chart)

### 특징

- 프로젝트 일정과 진행 상황을 막대 형태로 표시
- X축은 시간을, Y축은 작업이나 리소스를 나타냄
- 작업 간의 의존성과 중첩을 시각적으로 표현

### 활용 예시

- 프로젝트 일정 관리
- 리소스 할당 계획
- 생산 일정 관리
- 이벤트 기획

### 언제 사용해야 할까

- 프로젝트 일정과 진행 상황을 추적하고 싶을 때
- 작업 간의 시간적 관계와 의존성을 보여주고 싶을 때
- 여러 작업이나 리소스의 일정을 조정하고 싶을 때
![](/notes-assets/20250228084313.png)
## 11. 워드 클라우드(Word Cloud)

### 특징

- 텍스트 데이터에서 단어의 빈도를 크기로 표현
- 자주 등장하는 단어일수록 더 크게 표시
- 텍스트 데이터의 주요 키워드를 직관적으로 파악 가능

### 활용 예시

- 소셜 미디어 트렌드 분석
- 고객 리뷰 핵심 키워드 파악
- 설문조사 응답 분석
- 뉴스 기사의 주제 요약

### 언제 사용해야 할까

- 텍스트 데이터의 주요 키워드를 강조하고 싶을 때
- 단어 빈도를 시각적으로 표현하고 싶을 때
- 복잡한 텍스트 데이터의 개요를 빠르게 파악하고 싶을 때
![](/notes-assets/20250228084609.png)
## 12. 지도 시각화(Map Visualization)

### 특징

- 지리적 데이터를 지도 위에 표현
- 색상, 표식, 버블 등을 사용하여 지역별 데이터 표시
- 지역간 비교와 공간적 패턴 파악에 유용

### 활용 예시

- 지역별 매출 분포
- 인구 통계학적 정보 지도화
- 질병 발생률 지도
- 기상 데이터 표현

### 언제 사용해야 할까

- 데이터에 지리적 요소가 중요할 때
- 지역 간 비교를 시각적으로 표현하고 싶을 때
- 공간적 패턴이나 지리적 분포를 보여주고 싶을 때
![](/notes-assets/20250228084637.png)
## 결론

다양한 데이터 시각화 유형은 각각 고유한 장점과 활용 방법을 가지고 있습니다. 효과적인 데이터 시각화를 위해서는 전달하고자 하는 메시지, 데이터의 특성, 대상 청중을 고려하여 적절한 시각화 유형을 선택하는 것이 중요합니다. 또한, 여러 시각화 유형을 조합하여 대시보드를 구성하면 다양한 관점에서 데이터를 분석하고 인사이트를 얻을 수 있습니다.

데이터 시각화는 단순히 그래프를 그리는 것이 아니라, 데이터가 말하는 이야기를 효과적으로 전달하는 것입니다. 적절한 시각화 유형의 선택은 복잡한 데이터를 쉽게 이해하고 의사 결정에 활용할 수 있게 해주는 중요한 요소입니다.
