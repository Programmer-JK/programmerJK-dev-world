## 한 일

- **화면 다운로드**: html2canvas, html-to-image로 대시보드를 이미지로 저장하는 기능을 파고들었다. 외부 CSS와 이미지가 CORS 때문에 그려지지 않는 문제를 하나씩 확인했다.
- **위젯**: KPI 위젯 포맷과 게이지 위젯(Solid 게이지 포함)을 만들고, 복사/붙여넣기를 개선했다.
- **다국어**: LocaleService와 언어팩 구조를 설계하고, 동적으로 생기는 요소까지 번역되게 했다. 언어팩 유효성 검증과 기본값 처리도 넣었다.
- **테마**: 테마 색 API를 설계하고 다크 테마에 도전했다.
- **테스트**: 테스트 시나리오를 쓰고 Playwright로 자동화했다. `codegen`으로 기록하고 여러 브라우저에서 돌렸다.
- **새 프로젝트**: 6월부터는 라이선스 판매 플랫폼을 맡았다. 화면설계서, 업무 흐름도, DB 설계, 기술 아키텍처 문서, API 문서, WBS까지 처음부터 만들었다.

## 배운 것

- 브라우저 보안 정책은 우회할 대상이 아니라 설계의 전제다. 캡처 기능은 "같은 origin의 리소스만 쓴다"를 먼저 정했어야 했다.
- 다국어는 문자열 교체가 아니라 구조 문제다. 나중에 생기는 DOM까지 생각해야 한다.
- 설계 문서를 먼저 쓰면 회의가 짧아진다.

## 아쉬운 것

- 테스트 자동화를 기능 개발 막바지에 도입했다. 처음부터 있었다면 리팩토링이 덜 무서웠을 것이다.

## 다음

- 설계한 플랫폼을 실제로 배포하기.
