2월 말 소프트인에 입사했다. 첫 업무는 대시보드 빌더에서 차트 위젯의 속성을 편집하는 사이드바였다.

## 한 일

- 차트 종류(column, bar, line, pie, area)별로 필요한 속성을 다시 정의했다. pie에는 축이 필요 없고 `plotOptions`가 핵심이라는 식으로, 차트마다 "보여 줄 설정"을 추려 냈다.
- 폼 입력값을 설정 객체로 바꾸는 기능을 만들었다. FormData를 중첩 객체로 변환하는 방법은 따로 글로도 정리했다.
- 툴팁이 맨 위 카드에서 가려지는 문제, 위젯이 설정 그리드에 올라가는 문제 같은 버그를 잡았다.
- 사이드바를 `absolute`에서 `fixed`로 바꾸고, 아코디언과 한 번에 열고 닫기 기능을 넣었다.
- CSS를 파트별로 나누고 중복을 걷어냈다.
- Yarn Berry PnP 모드에서 lodash-es 모듈을 못 찾는 문제를 해결했다.

## 배운 것

- 설정 UI는 "가능한 모든 옵션"이 아니라 "사용자가 실제로 바꾸는 옵션"을 고르는 일이다. 속성 정의에 시간을 쓴 게 개발 시간을 줄여 줬다.
- 차트 종류마다 의미 있는 속성이 다르다. [Bar 차트와 Column 차트의 차이](/posts/bar-vs-column-chart)도 이때 정리했다.

## 아쉬운 것

- 기능을 붙이는 속도를 CSS 구조가 따라가지 못했다. 리팩토링을 더 일찍 했어야 했다.
