## 들어가며

최근 LLM 애플리케이션 개발에서 LangChain Expression Language(LCEL)이 주목받고 있습니다. 2023년 8월 LCEL 출시로 LangChain이 POC(개념 증명)에서 프로덕션까지 전환할 수 있는 도구가 되면서 많은 개발자들이 관심을 갖고 있지만, 기존의 전통적인 코딩 방식과 다른 문법 때문에 정확히 무엇인지 이해하기 어려운 것도 사실입니다.

## LCEL이란?

### 기본 개념

LCEL은 기존 Runnable들로부터 새로운 Runnable을 구축하는 선언적 접근 방식으로, 어떻게 실행할지가 아니라 무엇을 실행할지를 설명하여 LangChain이 런타임 실행을 최적화할 수 있게 합니다.

### 등장 배경

- **기존 문제**: LangChain이 주로 POC용 라이브러리였으며, 복잡하고 확장 가능한 애플리케이션을 만들 수 있는 능력이 부족했습니다.
- **해결 방식**: 파이프 연산자(|)를 사용해 LangChain 컴포넌트들을 체인으로 연결하는 "미니멀리스트" 코드 레이어를 제공합니다.

### 핵심 특징

1. **선언적 방식**: 어떻게 실행할지가 아니라 무엇을 실행할지를 설명하여 최적화된 실행을 가능하게 합니다.
2. **파이프 연산자**: 파이프 기호(|)를 사용해 AI 구성 요소들을 연결하여 정보가 한 부분에서 다른 부분으로 원활하게 흐르도록 합니다.
3. **자동 최적화**: 병렬 실행, 스트리밍, 비동기 지원을 자동으로 제공합니다.

## 동작 원리

### 기본 구조

LCEL 체인은 기존 Runnable들을 조합하여 구축되며, 주요 구성 원시 요소는 RunnableSequence와 RunnableParallel입니다.

```python
from langchain.chat_models import ChatOpenAI
from langchain.prompts import ChatPromptTemplate
from langchain.schema.output_parser import StrOutputParser

# 기본 컴포넌트 초기화
prompt = ChatPromptTemplate.from_template("다음 주제에 대해 간단히 설명해주세요: {topic}")
model = ChatOpenAI()
output_parser = StrOutputParser()

# LCEL을 사용한 체인 생성
chain = prompt | model | output_parser
```

### 주요 구성 요소

- **RunnableSequence**: 여러 Runnable을 순차적으로 체인하며, 한 Runnable의 출력이 다음의 입력으로 제공됩니다.
- **RunnableParallel**: 여러 Runnable을 동시에 실행하며, 각각에 동일한 입력을 제공합니다.

## 기존 기술과의 차이점

|비교 항목|기존 LangChain 체인|LCEL|
|---|---|---|
|코드 스타일|클래스 기반 체인|파이프 연산자 기반|
|병렬 처리|수동 구현 필요|자동 최적화|
|스트리밍|복잡한 설정|내장 지원|
|디버깅|프롬프트 등 중요한 세부사항이 숨겨짐|LangSmith에 모든 단계가 자동 로그|

### 언제 사용해야 할까?

✅ **사용하면 좋은 경우**

- 간단한 체인(예: 프롬프트 + LLM + 파서, 간단한 검색 설정 등)
- 병렬 처리나 스트리밍이 필요한 경우
- 프로덕션 배포를 고려하는 경우

❌ **사용하지 않는 것이 좋은 경우**

- 단일 LLM 호출만 하는 경우
- 복잡한 체인(분기, 사이클, 다중 에이전트 등)의 경우 LangGraph 사용 권장

## 실전 예시

### 간단한 구현

```python
from langchain_cohere import ChatCohere
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 단계별 문제 해결을 위한 프롬프트
prompt = ChatPromptTemplate.from_template("""
다음 수학 문제를 단계별로 해결해보세요:

문제: {question}

단계별 해결 과정:
1. 문제 이해
2. 계산 과정
3. 최종 답안
""")

# LLM 모델과 출력 파서 설정
model = ChatCohere(model="command-r-plus")
output_parser = StrOutputParser()

# LCEL 체인 구성
chain = prompt | model | output_parser

# 체인 실행
question = """
사과 5개가 있습니다. 2개를 버리고 1개를 먹었습니다. 
남은 사과는 몇 개인가요?
"""

response = chain.invoke({"question": question})
print(response)
```

### 활용 사례

1. **RAG 시스템**: RunnablePassThrough, RunnableParallel, RunnableLambda를 조합하여 검색-증강-생성 시스템 구현
2. **다중 모델 파이프라인**: 여러 모델을 병렬로 실행하거나 순차적으로 연결하여 복합적인 AI 워크플로우 구축

## 마무리

LCEL은 텍스트 처리 작업의 효율성과 유연성을 향상시키는 중요한 도구입니다. 특히 POC에서 프로덕션으로의 전환이 필요한 상황에서 큰 도움이 될 것 같습니다.
