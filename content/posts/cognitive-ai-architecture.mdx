## 1. 인지 에이전트 아키텍처 이론적 기반

### 1.1 인지 에이전트의 정의와 핵심 개념

인지 에이전트란 **인간의 인지 능력을 모델링한 AI 시스템**으로, 지각(Perception), 계획(Planning), 의사결정(Decision), 실행(Action)의 PPDA 모델을 기반으로 합니다. 이는 단순한 반응형 시스템을 넘어 **상황을 이해하고 추론하여 목적지향적 행동을 수행**하는 시스템입니다.

**인지 에이전트의 핵심 특성:**

- **상황 인식**: 환경을 이해하고 맥락을 파악
- **추론 능력**: 불완전한 정보로부터 결론 도출
- **적응성**: 새로운 상황에 대한 유연한 대응
- **목적 지향성**: 명확한 목표를 향한 체계적 접근
- **학습 능력**: 경험으로부터 지속적 개선

### 1.2 CoALA 프레임워크 기반 언어 에이전트 아키텍처
https://arxiv.org/abs/2309.02427

**Cognitive Architectures for Language Agents (CoALA)** 는 현대 언어 에이전트의 설계 프레임워크로, 다음 구성 요소를 포함합니다:

#### 1.2.1 모듈형 메모리 시스템

##### Cognitive architectures for language agents (CoALA) - Soar 아키텍처
A) 상호 작용하는 모듈과 프로세스의 집합, LLM, 내부 메모리, 외부 환경과 상호 작용하는 절차 표시
B) 에이전트의 의사 결정 절차는 시간적으로 외부 환경과의 루프에서 의사 결정 주기를 실행
![](/notes-assets/20251111100527.png)


- **작업 메모리 (Working Memory)**: 현재 처리 중인 정보
- **장기 메모리 (Long-term Memory)**: 도메인 지식과 경험
- **에피소드 메모리 (Episodic Memory)**: 과거 상호작용 이력
- **의미 메모리 (Semantic Memory)**: 구조화된 개념 지식

#### 1.2.2 구조화된 액션 공간

- **Grounding actions**: 외부 환경과 상호작용
	- **Physical environments**: 로봇 제어와 같이 지각 입력(perceptual inputs)을 텍스트로 처리하고 언어 기반 명령을 통해 물리적 환경에 영향을 줌
	- **Dialogue with humans or other agents**: 인간 또는 다른 에이전트와의 언어적 상호작용을 통해 명령을 수락하거나 학습하고, 도움이나 설명(clarification)을 요청하거나, 사회적 시뮬레이션에 참여
	- **Digital environments**: 게임, API, 웹사이트, 코드 실행과 같은 디지털 환경과 상호작용
- **Retrieval actions**: 장기 기억에서 정보를 읽어 작업 기억으로 정보 이동
- **Reasoning actions**: 작업 기억의 내용을 처리하여 새로운 정보를 생성. 최신 관찰, 궤적(trajectory), 검색된 정보에 대한 요약 및 통찰(insights)을 추출하여 학습 또는 의사 결정을 지.
- **Learning actions**: 장기 기억에 정보를 쓰는 과정을 통해 학습 진행.
	- Episodic Memory에 경험 업데이트.
	- Semantic Memory에 지식 업데이트(예: Reflexion이 실패한 에피소드에 대한 reflection을 저장).
	- LLM 파라미터(Procedural Memory) 업데이트(fine-tuning, RLHF 등).
	- 에이전트 코드(Procedural Memory) 업데이트(prompt templates, code-based skills, retrieval 절차, 학습/의사 결정 절차 업데이트).

#### 1.2.3 일반화된 의사결정 프로세스

- **Planning stage**: 추론 및 검색 액션을 유연하게 적용하여 대안을 제안, 평가하고 선택
	- **Proposal**: 하나 이상의 액션 후보를 생성. LLM 추론을 통해 생성 또는 if-else, while-if 코드 구조를 통해 생성.
	- **Evaluation**: 여러 액션이 제안된 경우, 각 액션에 가치를 할당. 휴리스틱 규칙, LLM 값, 학습된 값, LLM 추론을 조합하여 사용.
	- **Selection**: 액션과 그 가치를 바탕으로 실행할 액션을 선택하거나 제안 단계로 회귀.
- **Execution stage**: 선택된 액션(grounding 또는 learning)을 실행. 환경으로부터 피드백을 받아 다음 주기로 진행.

### 1.3 뇌 영감 에이전트 아키텍처

최신 연구에서 제시하는 **Brain-inspired Agent Architecture** 는 인간 뇌의 피질 영역 연결성을 모델링합니다:

- **Default Mode Network (DMN)**: 휴식 상태에서의 반성과 기억 처리
- **Executive Control Network (ECN)**: 작업 기억, 의사결정, 계획
- **감정 조절 네트워크**: 정서적 의사결정 지원
- **언어 네트워크**: 자연어 처리 및 이해
